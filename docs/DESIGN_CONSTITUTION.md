# Design Constitution

## Character

Warm paper, dark ink/navy, muted gold, restrained sage, serif display type, and clean sans-serif body type. The product should feel editorial and instrument-like, not like a SaaS template or decorative portfolio.

## Hierarchy

1. Current idea or action
2. Evidence or example
3. Navigation and metadata
4. Decoration

Only a few elements in a viewport may appear strongly elevated. Depth supports active state; stable content stays visually grounded.

## Widths and rhythm

- **Text:** short reading measures
- **Article:** long-form teaching
- **Standard:** normal sections
- **Workspace:** tools and diagrams
- **Bleed:** intentional full-width moments

Alternate dense, medium, immersive, and quiet sections. Large padding alone is not breathing room.

## Interaction and motion

Motion must explain a relationship, reflect state, respond to input, or orient the user. Remove it when no information would be lost. Keep browser scrolling normal and honor reduced-motion preferences.

## Accessibility and responsive behavior

Use semantic landmarks and headings, labels/legends, visible focus, keyboard-operable controls, disclosure with native semantics where possible, text or shape state cues in addition to color, and readable contrast. Reduce overlap and depth on tablet; use clear single-column layouts on mobile with no horizontal overflow or nested scroll traps.

## Asset priority

Student artifact → worked-example content → meaningful SVG → real product UI → technical diagram → photography → decoration.
